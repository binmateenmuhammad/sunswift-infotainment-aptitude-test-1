1. What makes a race car infotainment system different from a normal mobile app?

It needs to update in real time and confirm changes instantly, so the driver always knows what's actually happening with the car. Security matters a lot too — no unauthorized access or changes, since that could affect how the car drives. It also has to be dead simple, since a new driver might jump in mid-race and won't have time to learn a complex UI. Big icons, optional text labels, and one-handed gestures make it usable at speed without distraction. And if something breaks, it needs a backup plan like auto-switching off the AC if there's a fault, rather than just failing silently.

2. Four key principles of good infotainment design

Minimal driver distraction: 
The UI should be simple enough that any driver can use it without thinking too hard. If it's confusing, the driver's attention goes to the screen instead of the road, which is dangerous at race speed.

Fail-safe behaviour:
There should always be a backup if something breaks, especially for safety-critical stuff like traction control. A bug that stops traction control from kicking in could cause the car to slip or spin out.

Accurate, up-to-date data:
Things like battery charge need to be correct in real time, since the driver relies on it to decide when to stop. Wrong info here could leave them stranded.

Configurability:
Drivers should be able to adjust settings themselves so the car performs at its best in different conditions. If the drive mode is stuck on something like "eco/city," the car won't perform properly off-road or on track.

3. How I'd test it for safety and reliability

I'd try to break in to check for unauthorized access. I'd cut power mid-session to see how it reboots, and run it on weaker hardware to make sure the basics still work if things overheat. I'd also try changing critical settings like traction control mid-drive to confirm it's blocked, and cut power mid-drive to check it holds its state instead of resetting to default.

I'd also do some physical, real-world testing, spilling water on the screen to check it doesn't register any accidental button presses, and heating it up with direct sunlight and hardware heat to see how it holds up. I'd check screen brightness and visibility in direct sunlight, since glare could easily make it unreadable at the wrong moment. I'd also physically check that the screen is easy to reach and use for both the driver and passenger, and that the mounting angle actually makes sense from the driver's seat.
